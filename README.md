### 👨‍💻 Sobre Mim

- 🔭 Desenvolvedor focado na construção de aplicações web completas, combinando back-ends resilientes com interfaces modernas e reativas.
- ☕ **Back-End:** Especial interesse no ecossistema **Java** com **Spring Boot**, além de **Node.js** e **TypeScript** para microsserviços e APIs RESTful.
- ⚛️ **Front-End:** Desenvolvimento de SPAs e interfaces fluidas com **React**, **Next.js** e **Tailwind CSS**.
- 🐍 **Automações:** Scripts inteligentes e integrações com **Python**.
- 🚀 Boas práticas de desenvolvimento: arquitetura em camadas, Clean Code, containerização com Docker e CI/CD.
